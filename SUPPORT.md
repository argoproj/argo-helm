# Support

Argo Helm is maintained by volunteers, so support is best effort.

## Getting Help

Ask questions in the `#argo-helm-charts` channel on the [CNCF Slack](https://argoproj.github.io/community/join-slack).

## Reporting Bugs and Requesting Features

Open a [GitHub issue](https://github.com/argoproj/argo-helm/issues/new/choose) with the bug report or feature request template.

Report problems with the Argo applications themselves, rather than with the charts, to the upstream project:

* [Argo CD](https://github.com/argoproj/argo-cd/issues)
* [Argo Workflows](https://github.com/argoproj/argo-workflows/issues)
* [Argo Events](https://github.com/argoproj/argo-events/issues)
* [Argo Rollouts](https://github.com/argoproj/argo-rollouts/issues)
* [Argo CD Image Updater](https://github.com/argoproj-labs/argocd-image-updater/issues)

## Security Issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) instead.

## Supported Versions

See the [version support policy](README.md#version-support-policy).
